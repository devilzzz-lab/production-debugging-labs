<h2>🛠️ Quick Commands</h2>
<pre>
# GitHub Actions Commands
gh run list
gh run view &lt;run-id&gt;
gh run watch

# View Logs
gh run view --log

# Re-run Workflow
gh run rerun &lt;run-id&gt;

# Local Debugging (act)
act -j &lt;job-name&gt;
</pre>
